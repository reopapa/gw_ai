# 사내 그룹웨어 AI 기안/품의서 초안 생성 시스템 구동 방식 및 업무 흐름 (One-Page Brief)

본 문서는 사내 그룹웨어 전자결재 연동 **'AI 기안/품의서 초안 생성 시스템'**의 전체적인 구동 아키텍처와 업무 처리 파이프라인(End-to-End 흐름)을 한눈에 파악할 수 있도록 A4 1페이지 분량으로 정리한 요약 보고서입니다.

---

## 1. 시스템 2-Track 구동 아키텍처

실운영 그룹웨어(서버 A)의 성능 부하를 원천 차단하고 사내 보안을 유지하기 위해 **2개의 독립된 트랙(Track)**으로 이원화하여 구동됩니다.

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  [Track 1: 데이터 준비]                                                                │
│  그룹웨어 실운영 DB (서버 A) ──(일일 배치 gw_ai.py)──> AI 전용 DB 색인 적재 (서버 B)       │
│                                                                  │ (유사문서 메타데이터)│
│  [Track 2: 실시간 작성]                                          ▼                     │
│  사용자 웹 브라우저 (Streamlit app.py) <──(4단계 AI 파이프라인)─┘                      │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

* **Track 1. 백그라운드 AI 배치 색인화 (`gw_ai.py`)**
  - 실운영 DB(서버 A)에서 결재 완료된 문서를 수집하여, Gemini가 **핵심 키워드 10개와 3~5문장 요약**을 추출한 후 AI 전용 DB(서버 B: `EAPPDocument_AI`)에 색인 메타데이터로 사전 적재합니다.
* **Track 2. 실시간 대화형 기안 작성 웹 서비스 (`app.py`)**
  - 임직원이 웹 화면에서 4단계 안내에 따라 정보를 입력하고 검증하면, 과거 승인 문서를 참고하여 완성도 높은 HTML 기안서 초안을 실시간 생성합니다.

## 2. 웹 기안 초안 생성 파이프라인 (End-to-End 4단계 흐름)

```
┌──────────────────────┐     ┌──────────────────────┐     ┌──────────────────────┐     ┌──────────────────────┐
│   STEP 1. 정보 입력   │ ──> │   STEP 2. 지식 탐색   │ ──> │   STEP 3. 핵심 설계   │ ──> │   STEP 4. 초안 완성   │
│   사번 / 양식 / 요약 │     │  2단계 RAG / 첨부파일│     │   스마트 팩트체크 보드│     │  단락별 수정 / 복사  │
└──────────────────────┘     └──────────────────────┘     └──────────────────────┘     └──────────────────────┘
```

### STEP 1. 기본 정보 입력 및 사내 3중 권한 검증
- **정보 입력**: 사용자 사번, 결재 양식(기안, 품의, 지출결의 등), 문서 작성 개요(목적 및 배경) 입력
- **권한 보안**: 타 부서 기밀 문서 유출을 원천 방지하기 위해 **① 본인 작성, ② 본인 결재선 참여, ③ 소속 부서 결재**에 해당하는 최근 3년 치 문서만 실시간 권한 조인(`Cross-DB Query`)으로 안전하게 필터링

### STEP 2. 2단계 하이브리드 RAG 탐색 및 첨부파일 병렬 전처리
- **2단계 유사 문서 압축**: Gemini 1차 스크리닝(Top 25) ➔ **Cohere Reranker API** 정밀 재순위화로 가장 적합한 **상위 3건(Top 3)**을 최종 선정하고 실운영 서버에서 원본 본문(서식) 로드
- **첨부파일 병렬 처리**: 견적서·명세서를 병렬(`ThreadPoolExecutor`) 업로드하며, 특히 **엑셀(.xlsx)은 빈 행/열 제거 후 마크다운 표로 변환**하여 수치 왜곡 100% 방지
- **팩트 사전 추출**: 첨부파일에서 **거래처명, 품목, 단가, 수량, 총액**을 엄격한 JSON 데이터로 사전 강제 추출

### STEP 3. 스마트 팩트체크 보드 (Pre-fill & Auto-fill)
- **표준 체크리스트 도출**: 해당 기안이 통과하기 위해 필요한 **표준 핵심 요소 5~7개(도입배경, 소요예산, 기대효과 등)** 도출
- **검증 및 자동 완성**: 자료에 있는 내용은 미리 채워주고(**Pre-fill**), 누락된 항목은 빈칸으로 유도하여 사용자가 직접 보완하거나 AI가 문맥에 맞게 자동 보완(**Auto-fill**)

### STEP 4. 기안 초안 생성, 단락별 병렬 편집 및 감사 이력 영구 보관
- **HTML 초안 생성**: 과거 문서의 서식(표 구조)을 계승하되, **수치와 품목은 첨부파일 팩트 데이터로 강제 덮어쓰기**하여 AI 환각(Hallucination)을 원천 차단한 순수 HTML 초안 생성 (`EAPPDocument_AI_Result`에 영구 저장)
- **단락별(Section) 부분 수정**: HTML 헤딩(`<h2>`) 기준으로 단락을 자동 분할하여 표시하며, 특정 단락의 **[💬 Comment]** 지시 시 해당 단락만 병렬 수정 (수정 전/후 내역: `EAPPDocument_AI_ChatLog`에 감사 기록)
- **원클릭 복사**: 상단 **[📋 전체 복사]** 버튼으로 그룹웨어 에디터에 서식 그대로 붙여넣어 즉시 결재 상신

## 3. 핵심 엔지니어링 특장점 요약

| **보안/권한** | 조직도·결재선 3중 결합 검증 (`EAPPProgress`, `Organization_Users` 조인) | 타 부서 대외비·기밀 문서 추천 원천 차단 |
